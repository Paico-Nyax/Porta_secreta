## Sobre o projeto

[O jogo é em primeira pessoa. O objetivo é achar a porta correta. O ambiente do jogo é minimalista]

## O que o projeto faz

- [O jogador movimenta o personagem usando as teclas WASD ou as setas.]
- [Ao clicar tecla "e", a porta fala se é a correta ou não.]
- [Quando acerta a porta correta, aparece uma mensagem de vitória.]

## O que o projeto contém


- **Scripts:** [Interacao.cs: interage com as portas. PlayerMov.cs: Controla o Player. Porta.cs: Porta. GerenciadorDePortas.cs: Gerencia as portas.]
- **Objetos principais:** [Player, Ground, Portas.]
- **Recursos usados:** [CharacterController, BoxCollider, TextMeshPro.]

## Controles
